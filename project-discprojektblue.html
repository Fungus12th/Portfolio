Godot GDScript 2D Game

DiscProjektBlue

A 2D game built collaboratively using the Godot engine.

About the Project

DiscProjektBlue is a basic 2D game built using the Godot engine as a collaborative project. It was an exploration into game development fundamentals — learning how scenes work, how to handle player input, manage game states, and put together simple game mechanics from scratch.

While it's a simple project, it was a great hands-on introduction to game dev concepts like sprite management, collision detection, and scene trees in Godot.

What I Learned

  • GDScript fundamentals and game logic
  • 2D sprite rendering and animation

  • Collaborative development using Git
